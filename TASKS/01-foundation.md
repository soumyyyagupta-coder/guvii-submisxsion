Read `PLAN.md` and `API_CONTRACT.md` first. Implement only this session's files: `backend/pom.xml`, `backend/src/main/java/com/example/courserec/Application.java`, files under `backend/src/main/java/com/example/courserec/auth/` and `.../profile/`, `backend/src/main/resources/`, and `backend/.gitignore`. Do not edit files owned by other sessions. Implement a runnable Spring Boot 3.x Java 21 REST application with Spring JDBC (no JPA), H2 default local persistence in MySQL mode, MySQL config profile, schema, idempotent sample course seeding, secure password hashes, random opaque bearer sessions stored as SHA-256 hashes, optional admin bootstrap, auth endpoints and profile endpoints exactly as contracted.
